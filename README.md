# LLM 应用基础能力实验报告

> 模型：`deepseek-flash`　|　时间：2026-10　|　作者：【你的名字】

## 摘要

本报告通过四组对照实验，评测该模型在数学推理任务上的表现，
并量化三种提升准确率的手段（思考模式、多次投票、上下文位置控制）
在准确率、成本、延迟三个维度上的代价。

主要结论：【先用三五句话把最重要的发现说完。目标是让人只看这一段就懂】

## 1. 背景与问题

在构建 LLM 应用时，"怎么让结果更准"有多个可选手段，但每个都有代价。
本实验要回答三个问题：

1. 基线准确率是多少？
2. 让模型"多想"（思考模式）和"多问几次"（投票），哪个性价比更高？
3. 信息在上下文中的位置，会影响模型找到它的概率吗？

## 8. 讨论与局限

**局限（必须认真写，这是报告可信度的来源）：**

1. **样本量小**：20 题，1 道题差 = 5 个百分点。【所以什么结论不能下】
2. **题目自拟**：难度分布主观，未做标注者一致性检验。
3. **单一模型**：结论不可外推到其他厂商或规模的模型。
4. **单次运行**：未做重复实验取均值，无法给出置信区间。
5. **实验二存在混杂因素**：`temperature` 在非思考模式下生效、思考模式下无效，两组间除"思考开关"外还多了采样随机性差异。
6. **实验四的填充文本是同质模板生成的**，可能比真实文档更容易被"模式跳过"，位置效应可能被低估。
